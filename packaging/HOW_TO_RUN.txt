SheetsHub — как запустить
========================

1. Распакуйте весь архив SheetsHub-Windows целиком в одну папку
   (можно в Program Files).
2. В папке должны быть рядом:
   - SheetsHub.exe
   - папка _internal   ← без неё программа НЕ запустится
   - папка webui       ← HTML-интерфейс Helix
   - config.yaml
3. Интерфейс — HTML-макет Helix (pywebview), один в один с дизайном.
   Старый CustomTkinter: перед запуском выполните
     set SHEETS_HUB_UI=ctk
4. Telegram: в блоке настроек на главном экране или в config.yaml.
5. credentials.json — рядом с exe или кнопка «JSON ключа».
6. Служебная таблица + «Сохранить для всех ПК» — общий список таблиц.
7. Запускайте SheetsHub.exe (или start_SheetsHub.bat).

Если программа в Program Files, сохранённые настройки пишутся в:
  %LOCALAPPDATA%\SheetsHub\
